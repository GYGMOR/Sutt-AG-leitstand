# SUTT Leitstand · ◆ JH

Branchensoftware der **Sutt AG** (Haushalt-Grossgeräte, Glattbrugg): Disposition, Aufträge, Kunden, Geräte, Lager,
Personal – und die **Techniker-App** fürs Handy. Klickbares Mockup mit erfundenen Testdaten, ohne Backend.
